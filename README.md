# YouTube Player (YTPlayer)
A YouTube Player with numerous features designed to provide a simple-to-use alternative to YouTube playlists that offers account-free streaming with no interruptions <sup>[1]</sup>.

<sup>[1]</sup> YTPlayer does not remove YouTube ads. To do this, you need an ad blocker.

## Requirements
1. The website must be the active tab in your browser window. If you wish to use another tab in the browser at the same time, move the player to a separate window. Failure to do this may result in unexpected pauses.

2. It is strongly recommended that you use an ad blocker, as YouTube loves to put ads in embeds.

## Notes on testing

This project is not tested very thoroughly on mobile devices or devices with small screens. Optimal performance may not be achievable on these devices.

Testing has mainly occurred on Firefox.

## How to use
Simply open the website. All you need is already on there.

## Live version
A hosted version of the project is available on the website (https://iwltechnology.github.io/ytplayer).

## Docs
The documentation can be found in the Wiki of this repository (https://github.com/IWLTechnology/ytplayer/wiki)

## Features
- No interruptions, given that you use an ad blocker.
- Ability to save, rename, copy and delete custom playlists.
- Import videos from YouTube video link or playlist link.
- Ability to set up hot links to control multiple aspects of the website (Advanced feature).
- All data is cached and stored to local storage.
- Back up feature
- Deep shuffle
- Per-playlist progress saving
